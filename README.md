# 上班摸鱼盯盘助手 Stock Watchlist Assistant

一款轻量级 Windows 桌面股票盯盘工具，支持 A股、美股、ETF和指数行情。

## v1.1.0 更新内容

- 修复场内 ETF 无法搜索和添加的问题
- 修复主要指数无法通过代码添加的问题
- 支持直接输入六位证券代码
- 自动识别上海、深圳和北京交易所
- 搜索服务不可用时仍可通过证券代码添加
- 修复部分中文证券名称显示异常

### 搜索示例

- `588000`：科创 50 ETF
- `510300`：沪深 300 ETF
- `399001`：深证成指
- `上证指数`：按名称搜索
- `AAPL`：美股
- `QQQ`：美股 ETF

> `000001` 可能表示上证指数或平安银行，请在搜索结果中选择正确标的。

## 功能特点

- 无需登录
- 支持 A股、美股、ETF和主要指数
- 支持集合竞价、盘前、盘中和盘后交易状态
- 美股扩展时段行情独立显示
- 支持价格和涨跌幅提醒
- 支持自选股票搜索、添加、删除和排序
- 支持透明背景、窗口透明度和始终置顶
- 支持窗口缩放、列表滚动和冻结表头
- A股新浪行情异常时自动切换腾讯行情

## 下载使用

普通用户请前往仓库右侧的 **Releases** 页面下载 Windows 免安装版本。

下载后解压全部文件，双击 `盯盘助手.exe` 即可运行，无需安装 Python。

> 软件需要联网获取行情数据。

## 源代码运行

需要 Python 3.9 或更高版本。

```powershell
python stock_ticker.py
```

桌面通知功能需要安装：

```powershell
python -m pip install plyer
```

## 数据来源

- A股：新浪财经、腾讯行情
- 美股、ETF及指数：新浪全球行情

行情可能存在延迟，仅供信息展示和学习交流，不构成任何投资建议。

## 隐私说明

用户的自选股票、提醒条件和界面设置仅保存在本地 `config.json` 中，不会上传到网络。
